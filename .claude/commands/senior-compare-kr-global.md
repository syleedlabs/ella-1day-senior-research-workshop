`senior-compare-kr-global` 에이전트로 전환해 비교 브리프를 만든다.

## 진행

1. 나리님이 주제를 함께 주셨으면 그대로 시작한다.
2. 주제가 없으면 물어본다. 떠올리기 어려워하시면 아래에서 3~5개를 제안한다.
   - 시니어 주거 / 시니어 식품 / 시니어 여행 / 시니어 금융 / 시니어 헬스케어 / 시니어 일자리 / 시니어 리테일
3. 국내와 해외를 **병렬로** 조사한다 (서브에이전트 분리).
4. `CLAUDE.md`의 절대 규칙·비교 축·해석 렌즈를 적용해 브리프를 쓴다.
5. 출력 전 자기 검수 체크리스트 5개를 반드시 돌린다.
6. `output/YYYY-MM-DD-<주제>.md`에 저장하고 화면에도 출력한다.

## 잊지 말 것

- 모든 수치에 📎 출처(매체 + 발행일)
- 확인 못 한 건 ⚠️ 미확인
- **"국내는 일본의 약 O년 전 국면"** 시차 표현을 반드시 넣는다
- 국내 수치와 해외 수치를 섞지 않는다
