**이 커맨드는 메인 대화에서 직접 수행한다.** `.claude/agents/senior-biz-idea.md`의 페르소나·형식을 읽어 그대로 따르되, 별도 서브에이전트로 전환하지 않는다 — 전환하면 진행 상황이 사용자 화면에서 보이지 않는다.

## 진행

1. `output/` 폴더에 최근 브리프가 있는지 먼저 확인한다.
   - 있으면 "이 브리프를 기반으로 할까요?" 하고 확인받는다.
   - 없으면 주제를 물어보고 **최소한으로만** 조사한다 (**검색 4회 이내**).
2. ⚠️ **브리프가 있으면 웹을 새로 뒤지지 않는다.** 브리프 안의 수치와 📎 출처만으로 카드를 쓴다. 방금 조사를 마쳤는데 또 검색하면 사용자를 두 번 기다리게 한다.
   - 브리프에 없어서 못 쓴 것은 지어내지 말고 `⚠️ 미확인`에 적는다.
3. 기회를 세 자리에서 찾는다 — 일본이 먼저 간 자리 / 인구가 만드는 자리 / 잘못 쪼개진 자리.
4. 카드 3~5장을 쓴다. 근거가 얕으면 **장수를 줄인다.**
5. 완성한 카드를 Task로 `senior-source-check` 서브에이전트에 넘겨 **📎 근거가 실제로 있는지** 검수받는다. **검수는 딱 한 번이다** — "수정 필요"면 고쳐서 출력하고 끝낸다. 다시 검수받지 않는다.
6. `output/YYYY-MM-DD-<주제>-기회카드.md`에 저장하고 화면에도 출력한다.

## 진행 표시 — 침묵하지 않는다

| 시점 | 이렇게 말한다 |
|---|---|
| 브리프 확정 직후 | "이 브리프로 카드를 씁니다. **1~2분** 걸려요." |
| 검수 넘길 때 | "근거가 제대로 붙었는지 검수자에게 넘겼습니다." |
| 저장 직후 | "`output/`에 `<파일명>`으로 저장했습니다." |

## 잊지 말 것

- "누구에게"는 나이대·거주형태·소비력까지 좁힌다 ("시니어"는 대상이 아니다)
- "걸림돌"을 비우지 않는다
- 각 카드에 📎 근거
- 사업성을 단정하지 않는다 — 판단 재료를 줄 뿐이다
