# 1-2. 명령어 익히기

::: tip Step 2 / 8 · Part 1
이 챕터에서 — 클로드 코드를 **여는 것부터** 시작해서, 자주 쓰는 슬래시 명령어·입력 모드·단축키를 손에 붙입니다.
:::

## [실습 0] 먼저, 클로드 코드를 열어요

명령어를 배우기 전에 **일할 자리부터** 잡습니다. 딱 두 단계예요.

**① 워크숍 폴더를 준비합니다**

강사가 드린 폴더(`senior-research-workshop`)를 바탕화면 같은 찾기 쉬운 곳에 풀어두세요.

**② 그 폴더에서 클로드 코드를 엽니다**

::: details Mac을 쓰신다면
1. 폴더를 **오른쪽 클릭** → `폴더에서 새로운 터미널 열기`
2. 검은 창이 뜨면 아래를 입력하고 Enter

```
claude
```
:::

::: details Windows를 쓰신다면
1. 폴더를 연 뒤 주소창에 `cmd` 를 입력하고 Enter
2. 검은 창이 뜨면 아래를 입력하고 Enter

```
claude
```
:::

::: warning 반드시 **그 폴더에서** 열어야 해요
클로드 코드는 **열린 폴더 안**만 봅니다. 다른 곳에서 열면 오늘 쓸 `/senior-...` 명령어들이 아예 목록에 안 떠요.

확인법: `/help`를 쳤을 때 `senior-`로 시작하는 명령어가 보이면 제대로 열린 겁니다. 안 보이면 창을 닫고 ②를 다시 해주세요.
:::

## [개념] 승인 창이 뜨면 당황하지 마세요

클로드 코드는 파일을 만들거나 웹을 검색하기 전에 **"해도 될까요?"를 물어봅니다.**

```
  Do you want to proceed?
  ❯ 1. Yes
    2. Yes, and don't ask again for this
    3. No
```

이런 게 뜨면 멈춘 게 아니라 **나리님 대답을 기다리는 중**이에요. `1`을 누르고 Enter 하시면 계속 진행됩니다.

::: tip 오늘은 2번을 권해요
같은 작업이 반복될 때 **2번(`don't ask again`)** 을 고르시면 다음부터 안 물어봅니다. 오늘은 웹 검색을 여러 번 하니까, 처음 한 번만 2번으로 눌러두시면 훨씬 매끄러워요.
:::

## [개념] 자주 쓰는 슬래시 명령어

대부분의 일은 **평소 말로** 부탁하시면 돼요 — *"이 주제 좀 조사해줘"*. 다만 자주 쓰는 기능은 `/`로 시작하는 **슬래시 명령어**로 미리 만들어져 있어요. 외울 필요 없어요 — 전체는 `/help`로 언제든 볼 수 있습니다.

**세션 관리 (제일 많이 씀)**
| 명령 | 하는 일 |
|---|---|
| `/clear` | 대화를 초기화 (파일은 그대로 유지) |
| `/compact` | 대화를 압축 — 토큰 절약 + 앞부분 까먹기 방지 |
| `/resume` | 껐다 켜도 이전 대화를 복원 |

**모델 · 사용량**
| 명령 | 하는 일 |
|---|---|
| `/model` | Sonnet(빠름) ↔ Opus(똑똑함) 전환 |
| `/cost` | 이번 세션의 토큰·예상 비용 |
| `/usage` | 구독 플랜 사용량·한도 확인 |

**컨텍스트 · 파일**
| 명령 | 하는 일 |
|---|---|
| `/context` | 지금 인식 중인 파일 목록 보기 |
| `/add-dir` | 참고할 폴더 추가 |
| `/init` | 새 프로젝트에 `CLAUDE.md` 자동 생성 |
| `/memory` | 프로젝트 기억 확인·수정 |

**에이전트 · 권한 · 기타**
| 명령 | 하는 일 |
|---|---|
| `/agents` | 에이전트(리서치 봇) 생성·관리 |
| `/schedule` | 정해진 시각에 자동 실행되는 루틴 등록 (2-4·부록 D에서 씀) |
| `/loop` | 이 컴퓨터에서 반복 실행 (2-4에서 씀) |
| `/permissions` | 도구 사용 권한 설정 |
| `/help` · `/config` · `/doctor` | 전체 명령 보기 · 설정 · 문제 진단 |
| `/quit` · `/exit` | 클로드 코드 종료 |

## [개념] 입력 모드 — `Shift+Tab`으로 순환

클로드 코드는 "**어디까지 자동으로 승인할지**"를 모드로 정해요. `Shift+Tab`을 누르면 순환합니다.

| 모드 | 뜻 | 언제 |
|---|---|---|
| **accept edits on** | 파일 편집은 자동 승인, 셸 명령은 승인 요청 | 익숙해진 신뢰 작업 |
| **plan mode on** | 실행 전 **계획을 먼저 보여주고** 승인하면 실행 | 복잡한 작업을 단계별 확인 |
| **auto mode on** | 편집·명령 모두 자동 승인 | 완전 자동화 |

기본은 셋 다 꺼짐(수동 승인). 처음엔 기본으로 두고 감을 잡으세요.

::: tip 1-4 들어가기 전에 한 번 눌러두시면 좋아요
다음다음 챕터(1-4)에서는 봇이 웹을 여러 번 검색하고 파일도 만듭니다. 그때마다 승인 창이 뜨면 흐름이 끊겨요.

**1-4 시작 직전에 `Shift+Tab`을 두 번 눌러 `auto mode on`으로** 바꿔두시면 편합니다. 오늘 쓰는 건 조사·파일 저장뿐이라 안전해요. 워크숍이 끝나면 다시 기본으로 돌려두셔도 됩니다.
:::

## [개념] 키보드 단축키

| 단축키 | 기능 |
|---|---|
| `Esc` | 클로드 응답 중단 |
| `Esc` ×2 | 되감기 (대화만 또는 파일 변경까지) |
| `Shift+Tab` | 입력 모드 순환 |
| `Shift+Enter` | 줄바꿈 (여러 줄 입력) |
| `Ctrl+V` | 이미지 붙여넣기 |

## [개념] "더 생각해줘" 키워드

어려운 판단엔 `think` 계열 키워드를 붙이면 봇이 더 깊이 생각해요. (그만큼 시간·비용은 늘어요.)

| 키워드 | 언제 |
|---|---|
| `think` | 가벼운 비교·정리 ("이 두 문구 중 뭐가 더 끌려?") |
| `think hard` | 여러 요소를 동시에 고려하는 결정 |
| `ultrathink` | 되돌리기 어려운 중요한 결정 |

## [실습] 우리 워크숍 명령어 첫 실행

이번엔 **워크숍 슬래시 명령어**를 나리님이 직접 돌려봐요. 방금 연 클로드 코드에 이렇게 입력해 보세요.

```
/1-2-practice
```

봇이 **이 폴더를 직접 열어** 뭐가 들어 있는지 훑고, 오늘 무엇을 할지 안내해요. 대략 이런 답이 돌아옵니다.

```
이 폴더를 열어봤어요.

· docs/          워크북 (지금 보고 계신 이 자료)
· .claude/agents/  시니어 리서치 봇의 에이전트들
· .claude/commands/ 슬래시 명령어들
· output/        조사 결과가 쌓일 곳 (아직 비어 있어요)

오늘은 이 폴더의 시니어 리서치 봇을 직접 돌려봅니다.
```

화면 속 대화가 아니라 **실제 파일**을 다루는 게 보이실 거예요.

::: details 안 되면 — `/1-2-practice`가 목록에 없다고 나올 때
클로드 코드가 **다른 폴더에서 열렸을 가능성**이 큽니다. 창을 닫고 [실습 0](#실습-0-먼저-클로드-코드를-열어요)의 ②를 다시 해주세요.

그래도 안 되면 그냥 대화로 부탁하셔도 똑같이 동작해요 — *"이 폴더에 뭐가 들어 있는지 훑어서 알려줘"*
:::

이어서 조작 두 개만 더 손에 붙여봐요.

1. **`Shift+Tab`**을 눌러 입력 모드가 바뀌는 걸 보세요 (기본 → accept → plan → auto).
2. **`/compact`**로 대화를 압축하고, **`/cost`**로 사용량을 확인해 보세요.

::: tip 완벽히 외울 필요 없어요
나리님이 지금 다 못 외우셔도 괜찮아요. 막히면 `/help`, 헷갈리면 그냥 대화로 물어보시면 됩니다. 자주 쓰다 보면 손에 붙어요.
:::
