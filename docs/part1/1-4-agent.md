## 오늘 손에 넣을 결과물 3종

세 번의 실습으로 아래 셋을 직접 만드십니다. **지금은 훑어만 보세요.**

::: details ① 비교 브리프 — 주제 하나를 국내·해외로 파고든다
```
[시니어 리서치 봇] 국내·해외 비교 브리프

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 시장 규모 · 성장률 · 주요 플레이어
· 규제·인증 등 제도 환경

━━ 해외 (일본) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 같은 항목을 일본 기준으로
· 국내 대비 몇 년 앞서 있는지, 그때 무엇이 승부처였는지

💡 시사점 — 국내는 지금 일본의 몇 년 전 국면인가, 다음에 뭐가 오나
📎 출처 — 매체·발행일 명기
⚠️ 미확인 — 확인 못 한 항목은 솔직하게
💬 이어서 물어보실 것
```
:::

::: details ② 기회 카드 — 조사를 사업 언어로 번역한다
```
[기회 카드 ②] 시니어 특화 편의점 밀키트

  왜 지금인가   국내 고령친화식품은 아직 B2B 중심.
                일본은 편의점 진입 시점부터 시장이 커졌음.
  누구에게      혼자 사는 70대 초반 — 요리는 부담, 배달은 부담스러움
  왜 될 것 같나 이미 편의점 접근성은 세계 최고 수준
  걸림돌        1인분 소량 포장의 단가, 저염·연화 조리 기술

  📎 근거: (일본 사례 출처) / (국내 시장 출처)
  ⚠️ 미확인: 국내 시니어 편의점 이용 빈도 데이터 없음
```
:::

::: details ③ 주간 리포트 — 지난 한 주를 훑는다
```
[시니어 리서치 봇] 주간 리포트
기간: 2026-07-25 ~ 2026-08-01

━━ 이번 주 핵심 ━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. <한 줄 요약>
   <2~3줄 설명>  📎 <매체명> (<발행일>)

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· <항목>  📎 <매체명> (<발행일>)

💡 이번 주에 눈여겨볼 것
📌 이어서 파볼 만한 주제
```
:::

셋의 공통점이 세 가지예요 — **국내·해외를 교차**해서 본다는 것, **📎 출처**가 붙는다는 것, **⚠️ 모르는 건 모른다**고 말한다는 것.

## [개념] 왜 국내만 보지 않고 일본을 같이 볼까

해외를 보는 이유가 "참고삼아"가 아니에요. **국내의 다음 국면을 미리 보려고**입니다.

일본은 고령화를 우리보다 **먼저** 겪었어요. 그래서 일본 시장에서 이미 일어난 일은, 상당 부분 **국내에서 앞으로 일어날 일**입니다. 무엇이 통했고 무엇이 실패했는지가 이미 나와 있어요.

얼마나 먼저일까요? **어떤 지표로 재느냐에 따라 다릅니다.**

| 기준 | 일본 | 한국 | 시차 |
|---|---|---|---|
| 고령화율 **20%** (초고령사회) | 2005년 | 2025년 | **약 20년** |
| 고령화율 14% (고령사회) | 1994년 | 2017년 | 약 23년 |
| 고령화율 7% (고령화사회) | 1970년 | 2000년 | 약 30년 |

📎 일본 내각부 『고령사회백서』 / 국가데이터처 「2025 고령자 통계」(2025-09-30)

::: warning 시차는 줄어들고 있어요
표를 위에서 아래로 보시면 시차가 30년 → 23년 → 20년으로 **좁혀지고** 있죠. 한국이 일본보다 고령화 **속도가 빠르기** 때문이에요. (고령사회→초고령사회 전환: 일본 10~13년, 한국 **7년**)

그래서 봇은 "일본은 우리보다 O년 앞선다"를 **외운 숫자로 쓰지 않습니다.** 주제마다 해당 지표의 도달 연도를 비교해 그때그때 계산하고, **무엇을 기준으로 몇 년인지 밝히도록** 해뒀어요.
:::

```
        일본  ●━━━━━━━━━━━━━━━━━━━━━━━━━▶  (이미 지나온 길)
                        ↑
                  약 20년 (고령화율 20% 기준)
                        ↓
        국내  ●━━━━━━━━━━━━▶  (지금 여기)
                              ↑
                    "다음에 뭐가 올지" 를 일본에서 읽는다
```

::: details 봇이 결과를 해석하는 방식 — 렌즈 3가지와 파이프라인 (지금 안 읽으셔도 됩니다)
**비교 대상국은 일본 고정 + 미국 보조**

**일본**은 *시차*를 읽는 렌즈예요 — "우리는 일본의 몇 년 전인가". **미국**은 *규모와 자본*을 보는 보조 렌즈고요 — 시장이 커졌을 때 어디로 돈이 갔는지. 봇이 매번 다른 나라를 고르면 결과가 들쭉날쭉해져서 이 둘로 고정해뒀습니다.

**브리프가 나오는 [파이프라인](/part1/1-1-intro#terms)**

```
시니어 주제  →  국내 조사  →  해외 조사  →  시차·격차 해석  →  브리프 + 📎출처
                    └────── 동시에 진행 ──────┘
```

국내와 해외를 **동시에** 조사합니다. 왜 그렇게 되는지는 [2-1](/part2/2-1-agents)에서 뜯어봐요.

**해석 렌즈 3가지** — 정보를 나열만 하면 브리프가 아니라 스크랩이죠.

| 렌즈 | 무엇을 보게 하나 |
|---|---|
| **인구 피라미드 · 고령화율** | 시장이 얼마나 크고, 언제 그 규모에 도달하는가 |
| **액티브 시니어 vs 케어 시니어** | 같은 '시니어'를 소비력·니즈로 쪼갬 — 여행 가는 65세와 요양이 필요한 85세는 다른 시장 |
| **일본 선행 사례 → 국내 시차** | 검증된 모델이 국내에 언제·어떤 모습으로 오는가 |
:::

::: warning 봇이 만능은 아니에요
공개된 자료가 없는 건 봇도 못 찾습니다. 그럴 땐 지어내지 않고 `⚠️ 미확인`으로 표시해요. 브리프를 읽으실 때 **미확인 항목을 먼저 확인**하시면, 어디를 사람이 더 파야 하는지 바로 보입니다.
:::

## [실습 1] 비교 브리프 만들기

봇의 첫 번째 일이자 가장 많이 쓰실 기능이에요. **같은 일을 두 가지 방법으로** 해봅니다.

### Step 1 — 평소 말하듯 부탁하기

커맨드를 외울 필요 없어요. 조사하고 싶은 시니어 주제를 하나 정해서, 클로드 코드에 이렇게 입력해 보세요.

```
이 주제를 국내와 해외(특히 일본) 양쪽으로 조사해서 비교 브리핑해줘.
어디서 나온 정보인지 📎 출처를 붙이고, 확인 안 된 건 ⚠️ 미확인이라고 표시해줘.

주제: "시니어 주거 — 실버타운 말고 그다음 모델"
```

::: tip 주제가 안 떠오르시면
이런 것들로 시작해 보세요 — 시니어 식품 / 시니어 여행 / 시니어 금융 / 시니어 헬스케어 / 시니어 일자리 / 시니어 리테일.
:::

봇이 조사하는 데 **몇 분** 걸립니다. 웹을 실제로 뒤지고 있는 거예요. 기다리는 동안 멈춘 게 아니니 안심하세요.

### Step 2 — 결과 확인하기

화면에 대략 이런 게 흐릅니다.

```
국내 자료부터 찾아볼게요.

  ● 통계청 KOSIS — 고령자 가구 추계 조회
  ● 보건복지부 노인복지시설 현황 확인
  ● 일본 내각부 고령사회백서 확인

정리했습니다.

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 고령자 가구 수 …  📎 통계청 (2025-09-30)
...
```

**여기서 확인하실 건 모양이 아니라 세 가지예요.**

| # | 확인할 것 | 어디를 보나 |
|---|---|---|
| **1** | 국내와 해외를 **둘 다** 봤는가 | 국내 / 일본 두 덩어리가 있는지 |
| **2** | 숫자에 **📎 출처**가 붙었는가 | 매체명 + 발행일이 함께 있는지 |
| **3** | 확인 못 한 게 **⚠️ 미확인**으로 구분됐는가 | 없으면 오히려 의심해보세요 |

이 셋이 있으면 **성공입니다.** 방금 그 브리프가 나리님 손에서 나왔어요 🎉

::: warning 위 샘플과 모양이 다를 수 있어요 — 정상입니다
지금은 **평소 말하듯 부탁**한 거라, 앞에서 본 `━━ 국내 ━━` 같은 **정해진 틀은 안 나올 수 있어요.** 줄글로 답할 수도 있습니다.

**정해진 틀은 Step 3에서** 나와요 — 그게 커맨드가 하는 일이거든요.
:::

::: details 안 되면 — 출처가 안 붙거나 한쪽 나라만 조사했을 때
그냥 이어서 말씀하시면 됩니다.

```
일본 쪽도 같이 조사해서 비교해줘. 숫자마다 출처랑 발행일도 붙여줘.
```

클로드 코드는 **대화를 이어서 고칠 수 있어요.** 처음부터 다시 할 필요 없습니다.
:::

### Step 3 — 같은 일을 커맨드 한 줄로

잘 나왔지만, 이 부탁을 매번 타이핑하긴 번거롭죠. **같은 지침을 미리 담아둔 커맨드**가 있습니다.

```
/1-4-senior-compare-kr-global
```

::: tip 다 안 쳐도 돼요
`/1-4` 까지만 치면 오늘 실습용 커맨드 3개가 뜹니다. 방향키로 골라 Enter 치면 끝이에요.

(워크숍이 끝난 뒤에는 번호 없는 `/senior-...`를 쓰시면 되고, 그때는 `/senior`까지만 치시면 됩니다.)
:::

봇이 조사할 주제를 물어봐요. **Step 1과 다른 주제**로 해보시는 걸 권합니다 — 같은 주제면 뭐가 달라졌는지 안 보이거든요.

이번엔 앞에서 본 **정해진 틀 그대로** 나옵니다. 강사가 명령 한 줄로 크롤을 돌렸던 것과 같은 원리 — **자주 하는 일을 커맨드로 묶으면** 다음부턴 한 단어입니다.

| | Step 1 (대화) | Step 3 (커맨드) |
|---|---|---|
| 입력 | 매번 지침을 타이핑 | `/1-4-senior-...` 한 줄 |
| 출력 형식 | 그때그때 다름 | **매번 같은 틀** |
| 파일 저장 | 안 됨 | **`output/`에 자동 저장** |
| 언제 쓰나 | 한 번만 물어볼 때 | 반복해서 쓸 일 |

## [실습 2] 기회 카드

### Step 1 — 돌리기

브리프는 "지금 상황이 이렇다"까지예요. 그런데 나리님께 진짜 필요한 건 "**그래서 뭘 하지**"죠.

```
/1-4-senior-biz-idea
```

방금 만든 브리프를 **사업 언어로 번역**합니다.

### Step 2 — 결과 확인하기

워크숍에선 **3장** 정도 나와요 (평소 `/senior-biz-idea`로 부르시면 3~5장). [위에서 보신 ②번](#오늘-손에-넣을-결과물-3종) 형태입니다.

**`걸림돌` 칸을 꼭 보세요.** 좋은 얘기만 늘어놓지 않고 **안 될 이유까지 적게** 해뒀거든요. 조사에서 **의사결정 재료**로 넘어가는 지점이 여기예요.

## [실습 3] 주간 리포트

### Step 1 — 돌리기

마지막 하나예요. 주제를 정해서 파는 게 아니라, **지난 한 주 시니어 시장에 무슨 일이 있었는지** 훑는 겁니다.

```
/1-4-senior-weekly-news
```

### Step 2 — 결과 확인하기

국내외 뉴스·사례를 모아 [③번 형태](#오늘-손에-넣을-결과물-3종)의 리포트 한 장으로 정리해줘요.

::: tip 짧게 나와도 정상이에요 — 오히려 좋은 신호입니다
시니어 시장에 **매주 대단한 일이 일어나지는 않아요.** 조용한 주엔 핵심이 1~2개만 나오고, 정말 아무것도 없으면 *"이번 주는 특기할 만한 움직임이 없었습니다"*라고 씁니다.

봇에 **일부러 그렇게 지시해뒀어요.** 분량을 채우려고 약한 소식을 끼워 넣으면, 정작 중요한 주에 그게 안 보이거든요. 짧은 리포트는 실패가 아니라 **정직한 리포트**입니다.
:::

## [정리] 오늘 만든 것들, 어디에 있나

커맨드로 만든 결과물은 **화면에도 나오고 파일로도 남습니다.**

```
senior-research-workshop/
└── output/
    ├── 2026-08-08-시니어주거.md        ← 실습 1
    ├── 2026-08-08-기회카드-시니어주거.md  ← 실습 2
    └── 2026-08-08-주간리포트.md        ← 실습 3
```

열어보는 방법은 두 가지예요.

| 방법 | 어떻게 |
|---|---|
| **파일 탐색기로** | 폴더의 `output/` 을 열면 됩니다. `.md` 파일은 메모장으로도 열려요 |
| **클로드 코드에게** | *"output 폴더에 뭐가 있는지 보여줘"* 라고 말하면 목록을 읽어줍니다 |

::: tip 이게 쌓이면 나리님만의 아카이브가 돼요
오늘은 세 개지만, 주제를 볼 때마다 하나씩 쌓입니다. 반년 뒤엔 **시니어 시장을 나리님 관점으로 정리한 자료 뭉치**가 돼 있을 거예요.
:::

::: tip 여기서 질문 하나 남겨둘게요
방금 건 나리님이 **직접 쳐서** 돌린 거죠. 그런데 주간 리포트는 매주 해야 의미가 있는 일이잖아요.

> **매주 월요일 아침에 이게 알아서 돌아가게 하려면 어떻게 할까요?**

답은 Part 2의 [2-4 루프 엔지니어링](/part2/2-4-loop)에 있어요.
:::

## [체크포인트] 오늘의 하이라이트를 확인해요

- **국내·해외 비교 브리프를 받으셨나요?** (📎 출처가 붙어 있는지 확인해보세요)
- **대화로 한 번, 커맨드로 한 번** — 둘의 차이가 느껴지셨나요?
- **기회 카드까지 보셨나요?** 조사가 "그래서 뭘 하지"로 넘어가는 감이 오셨나요?
- **`output/` 폴더를 열어보세요.** 오늘 만든 파일들이 실제로 쌓여 있습니다.
- **⚠️ 미확인 항목이 있었나요?** 있었다면 좋은 신호예요 — 봇이 지어내지 않았다는 뜻이니까요.
