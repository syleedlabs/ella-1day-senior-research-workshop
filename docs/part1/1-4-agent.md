## 오늘 손에 넣을 결과물 3종

세 번의 실습으로 아래 셋을 직접 만드십니다. **지금은 훑어만 보세요.**

**① 비교 브리프** — 주제 하나를 국내·해외로 파고든다 (실습 1)

```
[시니어 리서치 에이전트] 국내·해외 비교 브리프

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 시장 규모 · 성장률 · 주요 플레이어
· 규제·인증 등 제도 환경

━━ 해외 (일본) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 같은 항목을 일본 기준으로
· 국내 대비 몇 년 앞서 있는지, 그때 무엇이 승부처였는지

━━ 해외 (미국) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
※ 자본·규모 관점이 필요한 주제에만 나옵니다 (시니어 금융·헬스케어 등)

💡 시사점 — 국내는 지금 일본의 몇 년 전 국면인가, 다음에 뭐가 오나
📎 출처 — 매체·발행일 명기
⚠️ 미확인 — 확인 못 한 항목은 솔직하게
💬 이어서 물어보실 것
```

**①번은 바로 다음 실습에서 만드실 거라** 펼쳐뒀어요. 나머지 둘은 각 실습에 가서 펼쳐보시면 됩니다.

::: details ② 기회 카드 — 조사를 사업 언어로 번역한다 (실습 2)
```
[기회 카드 ②] 시니어 특화 편의점 밀키트

  왜 지금인가   국내 고령친화식품 제조는 5조 원대지만 매출은 아직
                병원·요양시설 B2B 급식 중심. 소비자 매대는 비어 있음.
  누구에게      혼자 사는 70대 초반 — 요리는 부담, 배달은 부담스러움
  왜 될 것 같나 국내 편의점 밀도가 인구 약 1,000명당 1개로 세계 최고 수준
  걸림돌        1인분 소량 포장의 단가, 저염·연화 조리 기술

  📎 근거: 「실버푸드 5조 시장의 착시」 사설경제 (2026-07-24)
          「'편의점 대국' 日 넘어선 한국」 아시아경제 (2024-06-26)
  ⚠️ 미확인: 국내 시니어 편의점 이용 빈도 데이터 없음
  ⚠️ 미확인: 일본에서 편의점 진입이 시장 확대의 원인이었는지는
             확인하지 못함 (보도는 후기고령자 증가를 주 동인으로 설명)
```
:::

::: details ③ 주간 리포트 — 지난 한 주를 훑는다 (실습 3)
```
[시니어 리서치 에이전트] 주간 리포트
기간: <실행일 기준 지난 7일>

━━ 이번 주 핵심 3가지 ━━━━━━━━━━━━━━━━━━━━━━
1. <한 줄 요약>
   <2~3줄 설명>  📎 <매체명> (<발행일>)

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· <항목>  📎 <매체명> (<발행일>)

💡 이번 주에 눈여겨볼 것
⚠️ 미확인 — 확인 못 한 항목
📌 이어서 파볼 만한 주제
```
:::

셋의 공통점이 세 가지예요 — **국내·해외를 교차**해서 본다는 것, **📎 출처**가 붙는다는 것, **⚠️ 모르는 건 모른다**고 말한다는 것.

에이전트는 **국내와 일본을 늘 함께** 봅니다. 참고삼아가 아니라 **국내의 다음 국면을 미리 보려고**예요 — 일본이 우리보다 고령화를 **먼저** 겪었거든요.

:::: details 📖 [참고] 얼마나 먼저일까 — 시차를 재는 법 (지금 안 읽으셔도 됩니다)
얼마나 먼저인지는 **어떤 지표로 재느냐에 따라 다릅니다.**

| 기준 | 일본 | 한국 | 시차 |
|---|---|---|---|
| 고령화율 **20%** (초고령사회) | 2005년 | 2024년 12월 | **약 20년** |
| 고령화율 14% (고령사회) | 1994년 | 2017년 8월 | 약 23년 |
| 고령화율 7% (고령화사회) | 1970년 | 2000년 11월 | 약 30년 |

📎 한국 — 행정안전부 주민등록 인구통계 (2024-12-24 발표) / 일본 — 내각부 『고령사회백서』 (발행일 미상)

::: warning 기준을 바꾸면 숫자가 달라져요
위 표는 **주민등록 인구** 기준입니다. 국가데이터처의 **총인구 추계**로 재면 한국의 20% 도달이 2025년으로 잡혀요. 어느 쪽도 틀린 게 아니라 **모수가 다른 것**이라, 에이전트는 늘 *"무슨 기준으로 몇 년인지"*를 함께 밝히도록 해뒀습니다.

두 기준을 섞어 쓰면 안 됩니다 — 이 표에서 아래 계산을 뽑아낼 수 있는 것도 세 줄이 **같은 기준**이기 때문이에요.
:::

::: warning 시차는 줄어들고 있어요
표를 위에서 아래로 보시면 시차가 30년 → 23년 → 20년으로 **좁혀지고** 있죠. 한국이 일본보다 고령화 **속도가 빠르기** 때문이에요.

고령사회(14%) → 초고령사회(20%)에 걸린 시간을 표에서 직접 빼보시면 — **일본은 11년**(1994 → 2005), **한국은 7년**(2017 → 2024)입니다.

그래서 에이전트는 "일본은 우리보다 O년 앞선다"를 **외운 숫자로 쓰지 않습니다.** 주제마다 해당 지표의 도달 연도를 비교해 그때그때 계산하고, **무엇을 기준으로 몇 년인지 밝히도록** 해뒀어요.
:::

```
        일본  ●━━━━━━━━━━━━━━━━━━━━━━━━━▶  (이미 지나온 길)
                        ↑
                  약 20년 (고령화율 20% 기준)
                        ↓
        국내  ●━━━━━━━━━━━━▶  (지금 여기)
                              ↑
                    "다음에 뭐가 올지" 를 일본에서 읽는다
```

**브리프가 나오는 [파이프라인](/part1/1-1-intro#terms)**

```
시니어 주제  →  국내 조사  →  해외 조사  →  시차·격차 해석  →  브리프 + 📎출처
                    └────── 동시에 진행 ──────┘
```

국내와 해외를 **동시에** 조사합니다. 왜 그렇게 되는지는 [2-1](/part2/2-1-agents)에서 뜯어봐요.

**해석 렌즈 3가지** — 정보를 나열만 하면 브리프가 아니라 스크랩이죠.

| 렌즈 | 무엇을 보게 하나 |
|---|---|
| **인구 피라미드 · 고령화율** | 시장이 얼마나 크고, 언제 그 규모에 도달하는가 |
| **액티브 시니어 vs 케어 시니어** | 같은 '시니어'를 소비력·니즈로 쪼갬 — 여행 가는 65세와 요양이 필요한 85세는 다른 시장 |
| **일본 선행 사례 → 국내 시차** | 검증된 모델이 국내에 언제·어떤 모습으로 오는가 |
::::

::: tip 실습 전에 이 둘만 알아두세요
**① 미국이 같이 나올 수 있어요.** 시니어 **금융·헬스케어**처럼 자본 관점이 필요한 주제면 `━━ 해외 (미국) ━━` 가 하나 더 붙습니다. 일본은 *시차*, 미국은 *규모·자본* 렌즈예요.

**② 에이전트가 만능은 아니에요.** 공개 자료가 없는 건 에이전트도 못 찾습니다. 그럴 땐 지어내지 않고 `⚠️ 미확인`으로 표시해요.
:::

## [실습 1] 비교 브리프 만들기

에이전트의 첫 번째 일이자 가장 많이 쓰실 기능이에요. **같은 일을 두 가지 방법으로** 해봅니다.

### Step 1 — 평소 말하듯 부탁하기

커맨드를 외울 필요 없어요. 조사하고 싶은 시니어 주제를 하나 정해서, 클로드 코드에 이렇게 입력해 보세요.

```
이 주제를 국내와 해외(특히 일본) 양쪽으로 조사해서 비교 브리핑해줘.
어디서 나온 정보인지 📎 출처를 붙이고, 확인 안 된 건 ⚠️ 미확인이라고 표시해줘.

주제: "시니어 주거 — 실버타운 말고 그다음 모델"
```

::: tip 주제가 안 떠오르시면
이런 것들로 시작해 보세요 — 시니어 식품 / 시니어 여행 / 시니어 금융 / 시니어 헬스케어 / 시니어 일자리 / 시니어 리테일.
:::

::: tip 이 긴 부탁, 매번 치기 번거롭죠
그래서 **같은 지침을 미리 담아둔 커맨드**를 만들어뒀어요. `/`로 시작하는 한 줄이면 끝나고, **Step 3에서 그걸 씁니다.**

지금은 **직접 쳐보시는 게** 목적이에요. 그래야 Step 3에서 뭐가 편해졌는지 몸으로 느껴지거든요.
:::

에이전트가 조사하는 데 **몇 분** 걸립니다. 웹을 실제로 뒤지고 있는 거예요. 기다리는 동안 멈춘 게 아니니 안심하세요.

### Step 2 — 결과 확인하기

화면에 대략 이런 게 흐릅니다.

```
국내 자료부터 찾아볼게요.

  ● 통계청 KOSIS — 고령자 가구 추계 조회
  ● 보건복지부 노인복지시설 현황 확인
  ● 일본 내각부 고령사회백서 확인

정리했습니다.

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 고령자 가구 수 …  📎 국가데이터처 (2025-09-29)
...
```

**여기서 확인하실 건 모양이 아니라 세 가지예요.**

| # | 확인할 것 | 어디를 보나 |
|---|---|---|
| **1** | 국내와 해외를 **둘 다** 봤는가 | 국내 / 일본 두 덩어리가 있는지 |
| **2** | 숫자에 **📎 출처**가 붙었는가 | 매체명 + 발행일이 함께 있는지 |

**이 둘이 있으면 성공입니다.** 방금 그 브리프가 나리님 손에서 나왔어요 🎉

`⚠️ 미확인`은 **있어도 되고 없어도 됩니다.** 자료가 충분한 주제면 안 붙어요. 다만 **하나도 없는데 내용이 유난히 매끈하다면** 한 번 의심해보실 만합니다 — 에이전트가 모르는 걸 넘어갔을 수 있거든요.

::: warning 위 샘플과 모양이 다를 수 있어요 — 정상입니다
지금은 **평소 말하듯 부탁**한 거라, 앞에서 본 `━━ 국내 ━━` 같은 **정해진 틀은 안 나올 수 있어요.** 줄글로 답할 수도 있습니다.

**정해진 틀은 Step 3에서** 나와요 — 그게 커맨드가 하는 일이거든요.
:::

::: details 안 되면 — 출처가 안 붙거나 한쪽 나라만 조사했을 때
그냥 이어서 말씀하시면 됩니다.

```
일본 쪽도 같이 조사해서 비교해줘. 숫자마다 출처랑 발행일도 붙여줘.
```

클로드 코드는 **대화를 이어서 고칠 수 있어요.** 처음부터 다시 할 필요 없습니다.
:::

### Step 3 — 같은 일을 커맨드 한 줄로

Step 1에서 예고한 그 커맨드예요.

```
/1-4-senior-compare-kr-global
```

주제를 물어보면 **Step 1과 같은 걸로** 답해주세요. 같아야 무엇이 달라졌는지 보이거든요.

이번엔 **틀이 잡혀서** 돌아오고, `output/`에 **파일로도 남습니다.** 5~10분 걸리니 느긋하게 기다리세요.

::: details 중간에 "수정 필요"가 떠도 정상이에요
이런 게 지나갈 수 있습니다.

```
[검수 결과] 수정 필요
  ■ 지적 1. 시장 규모 수치에 발행일이 없습니다
```

**실패가 아니라 검수자가 일한 겁니다.** 에이전트 안에 만드는 쪽과 검사하는 쪽이 나뉘어 있어서, 지적이 나오면 고쳐서 다시 내요. 자세한 건 [2-3](/part2/2-3-harness)에서 다룹니다.
:::

## [실습 2] 기회 카드

### Step 1 — 돌리기

브리프는 "지금 상황이 이렇다"까지예요. 그런데 나리님께 진짜 필요한 건 "**그래서 뭘 하지**"죠.

```
/1-4-senior-biz-idea
```

방금 만든 브리프를 **사업 언어로 번역**합니다.

::: tip 에이전트가 먼저 되물어요
`output/`에서 방금 만든 브리프를 찾아 *"이 브리프를 기반으로 할까요?"* 하고 확인합니다. **답을 하셔야 진행돼요** — 화면이 멈춘 게 아니라 나리님을 기다리는 중입니다.
:::

### Step 2 — 결과 확인하기

[위에서 보신 ②번](#오늘-손에-넣을-결과물-3종) 형태로 나옵니다. **성공 기준은 장수가 아니에요.**

| 확인할 것 | |
|---|---|
| 각 카드에 **`걸림돌`이 채워져 있는가** | 이게 이 실습의 핵심입니다 |
| 각 카드에 **📎 근거**가 붙어 있는가 | 매체명 + 발행일 |

::: tip 2장만 나와도 정상입니다
워크숍에선 보통 **3장** 나와요 (평소 `/senior-biz-idea`로 부르시면 3~5장). 그런데 **근거가 얕으면 에이전트가 일부러 장수를 줄입니다.** 명세에 이렇게 적어뒀거든요 — *"3장짜리 진짜가 5장짜리 가짜보다 낫다."*

숫자가 적다고 실패가 아니에요. **`걸림돌`과 `📎 근거`가 비어 있으면** 그때 다시 돌려보세요.
:::

**`걸림돌` 칸을 꼭 보세요.** 좋은 얘기만 늘어놓지 않고 **안 될 이유까지 적게** 해뒀거든요. 조사에서 **의사결정 재료**로 넘어가는 지점이 여기예요.

## [실습 3] 주간 리포트

### Step 1 — 돌리기

마지막 하나예요. 주제를 정해서 파는 게 아니라, **지난 한 주 시니어 시장에 무슨 일이 있었는지** 훑는 겁니다.

```
/1-4-senior-weekly-news
```

### Step 2 — 결과 확인하기

국내외 뉴스·사례를 모아 [③번 형태](#오늘-손에-넣을-결과물-3종)의 리포트 한 장으로 정리해줘요.

::: tip 짧게 나와도 정상이에요 — 오히려 좋은 신호입니다
시니어 시장에 **매주 대단한 일이 일어나지는 않아요.** 조용한 주엔 핵심이 1~2개만 나오고, 정말 아무것도 없으면 *"이번 주는 특기할 만한 움직임이 없었습니다"*라고 씁니다.

에이전트에 **일부러 그렇게 지시해뒀어요.** 분량을 채우려고 약한 소식을 끼워 넣으면, 정작 중요한 주에 그게 안 보이거든요. 짧은 리포트는 실패가 아니라 **정직한 리포트**입니다.
:::

::: warning 다만 이건 구분하셔야 해요 — 조용한 주 vs 조사가 안 된 것
둘 다 짧게 나오지만 **📎 출처의 유무**로 갈립니다.

| | 어떻게 보이나 | 어떻게 하나 |
|---|---|---|
| **조용한 주** | 항목은 적어도 **📎 출처가 붙어 있음** | 정상. 그대로 두세요 |
| **조사가 안 됨** | **📎 출처가 하나도 없음** | 다시 돌려보세요. 그래도 같으면 *"지난 2주로 넓혀서 다시 훑어줘"* |
:::

## [정리] 오늘 만든 것들, 어디에 있나

커맨드로 만든 결과물은 **화면에도 나오고 파일로도 남습니다.**

```
senior-research-workshop/
└── output/
    ├── 2026-08-08-시니어주거.md            ← 실습 1 Step 3
    ├── 2026-08-08-시니어주거-기회카드.md    ← 실습 2
    └── 2026-08-08-주간리포트.md            ← 실습 3
```

(`시니어주거` 자리엔 나리님이 고르신 주제가 들어갑니다. **실습 1 Step 1은 파일로 안 남아요** — 저장은 커맨드가 하는 일이거든요.)

열어보는 방법은 두 가지예요.

| 방법 | 어떻게 |
|---|---|
| **파일 탐색기로** | 폴더의 `output/` 을 열면 됩니다. `.md` 파일은 메모장으로도 열려요 |
| **클로드 코드에게** | *"output 폴더에 뭐가 있는지 보여줘"* 라고 말하면 목록을 읽어줍니다 |

::: tip 이게 쌓이면 나리님만의 아카이브가 돼요
오늘은 세 개지만, 주제를 볼 때마다 하나씩 쌓입니다. 반년 뒤엔 **시니어 시장을 나리님 관점으로 정리한 자료 뭉치**가 돼 있을 거예요.
:::

## [체크포인트] 오늘의 하이라이트를 확인해요

- **국내·해외 비교 브리프를 받으셨나요?** (📎 출처가 붙어 있는지 확인해보세요)
- **대화로 한 번, 커맨드로 한 번** — 둘의 차이가 느껴지셨나요?
- **기회 카드까지 보셨나요?** 조사가 "그래서 뭘 하지"로 넘어가는 감이 오셨나요?
- **`output/` 폴더를 열어보세요.** 오늘 만든 파일들이 실제로 쌓여 있습니다.
- **⚠️ 미확인 항목이 있었나요?** 있었다면 에이전트가 **지어내지 않았다**는 뜻이에요. 없었다면 자료가 충분했던 거고요 — 둘 다 정상입니다.
