**③ 주간 리포트** · `/1-4-senior-weekly-news` (실습 3)

앞의 둘이 **주제 하나를 깊게** 파는 것이었다면, 이건 "**지난 한 주를 넓게**"입니다.

주제를 정해주실 필요도 없어요. 커맨드만 치시면 에이전트가 **지난 7일간의 국내외 시니어 소식을 훑어 한 장으로** 묶어줍니다. 이번 주 눈여겨볼 **핵심 3가지**를 먼저 뽑고, 그 아래 국내·해외를 나눠 정리해요.

매주 한 번씩 돌려두시면 시니어 시장에서 무슨 일이 벌어지는지 **놓치지 않게** 됩니다.

세 토글 안의 수치는 전부 **실제로 조사된 것**이에요. 다만 에이전트는 그때그때 웹을 새로 뒤지니, 같은 주제를 넣으셔도 **내용은 달라집니다.** 봐두실 건 숫자가 아니라 **모양**이에요.

셋 다 만들어지면 **화면에 바로 뜨고**, 동시에 `output/` 폴더에 **`.md` 파일로도 저장**돼요. 오늘 이후에 다시 열어보실 수 있습니다.

셋의 공통점도 세 가지 있어요 — **국내·해외를 교차**해서 본다는 것, **📎 출처**가 붙는다는 것, **⚠️ 모르는 건 모른다**고 말한다는 것.

에이전트는 **국내와 일본을 늘 함께** 봅니다. 참고삼아가 아니라 **국내의 다음 국면을 미리 보려고**예요 — 일본이 우리보다 고령화를 **먼저** 겪었거든요.

:::: details 📖 [참고] 왜 하필 일본인가 — 시차 재는 법 · 조사 흐름 · 해석 렌즈 (지금 안 읽으셔도 됩니다)
얼마나 먼저인지는 **어떤 지표로 재느냐에 따라 다릅니다.**

| 기준 | 일본 | 한국 | 시차 |
|---|---|---|---|
| 고령화율 **20%** (초고령사회) | 2005년 | 2024년 12월 | **약 20년** |
| 고령화율 14% (고령사회) | 1994년 | 2017년 8월 | 약 23년 |
| 고령화율 7% (고령화사회) | 1970년 | 2000년 11월 | 약 30년 |

📎 한국 — 행정안전부 주민등록 인구통계 (2024-12-24 발표) / 일본 — 내각부 『고령사회백서』 (발행일 미상)

::: warning 기준을 바꾸면 숫자가 달라져요
위 표는 **주민등록 인구** 기준입니다. 국가데이터처의 **총인구 추계**로 재면 한국의 20% 도달이 2025년으로 잡혀요. 어느 쪽도 틀린 게 아니라 **모수가 다른 것**이라, 에이전트는 늘 *"무슨 기준으로 몇 년인지"*를 함께 밝히도록 해뒀습니다.

두 기준을 섞어 쓰면 안 됩니다 — 이 표에서 아래 계산을 뽑아낼 수 있는 것도 세 줄이 **같은 기준**이기 때문이에요.
:::

::: warning 시차는 줄어들고 있어요
표를 위에서 아래로 보시면 시차가 30년 → 23년 → 20년으로 **좁혀지고** 있죠. 한국이 일본보다 고령화 **속도가 빠르기** 때문이에요.

고령사회(14%) → 초고령사회(20%)에 걸린 시간을 표에서 직접 빼보시면 — **일본은 11년**(1994 → 2005), **한국은 7년**(2017 → 2024)입니다.

그래서 에이전트는 "일본은 우리보다 O년 앞선다"를 **외운 숫자로 쓰지 않습니다.** 주제마다 해당 지표의 도달 연도를 비교해 그때그때 계산하고, **무엇을 기준으로 몇 년인지 밝히도록** 해뒀어요.

맨 위 **①번 브리프가 그 예**예요 — 시니어 *주거*가 주제라 인구 기준 20년이 아니라 **주거 제도 도입 기준으로 다시 재서 13년**이 나왔죠.
:::

```
        일본  ●━━━━━━━━━━━━━━━━━━━━━━━━━▶  (이미 지나온 길)
                        ↑
                  약 20년 (고령화율 20% 기준)
                        ↓
        국내  ●━━━━━━━━━━━━▶  (지금 여기)
                              ↑
                    "다음에 뭐가 올지" 를 일본에서 읽는다
```

**브리프가 나오는 [파이프라인](/part1/1-1-intro#terms)**

```
시니어 주제  →  국내 조사  →  해외 조사  →  시차·격차 해석  →  브리프 + 📎출처
                    └────── 동시에 진행 ──────┘
```

국내와 해외를 **동시에** 조사합니다. 왜 그렇게 되는지는 [2-1](/part2/2-1-agents)에서 뜯어봐요.

**해석 렌즈 3가지** — 정보를 나열만 하면 브리프가 아니라 스크랩이죠.

| 렌즈 | 무엇을 보게 하나 |
|---|---|
| **인구 피라미드 · 고령화율** | 시장이 얼마나 크고, 언제 그 규모에 도달하는가 |
| **액티브 시니어 vs 케어 시니어** | 같은 '시니어'를 소비력·니즈로 쪼갬 — 여행 가는 65세와 요양이 필요한 85세는 다른 시장 |
| **일본 선행 사례 → 국내 시차** | 검증된 모델이 국내에 언제·어떤 모습으로 오는가 |
::::

::: tip 실습 전에 이 둘만 알아두세요
**① 미국이 같이 나올 수 있어요.** 시니어 **금융·헬스케어**처럼 자본 관점이 필요한 주제면 `━━ 해외 (미국) ━━` 가 하나 더 붙습니다. 일본은 *시차*, 미국은 *규모·자본* 렌즈예요.

**② 에이전트가 만능은 아니에요.** 공개 자료가 없는 건 에이전트도 못 찾습니다. 그럴 땐 지어내지 않고 `⚠️ 미확인`으로 표시해요.
:::

## [실습 1] 비교 브리프 만들기

**커맨드**: 직접 치지 않으셔도 돼요 — 평소처럼 부탁하시면 `/senior-compare-kr-global` 이 **알아서 켜집니다**

에이전트의 첫 번째 일이자 가장 많이 쓰실 기능이에요.

### Step 1 — 평소 말하듯 부탁하기

커맨드를 외울 필요 없어요. 조사하고 싶은 시니어 주제를 하나 정해서, 클로드 코드에 이렇게 입력해 보세요.

```
이 주제를 국내와 해외(특히 일본) 양쪽으로 조사해서 비교 브리핑해줘.
어디서 나온 정보인지 📎 출처를 붙이고, 확인 안 된 건 ⚠️ 미확인이라고 표시해줘.

주제: "시니어 주거 — 실버타운 말고 그다음 모델"
```

::: tip 주제가 안 떠오르시면
이런 것들로 시작해 보세요 — 시니어 식품 / 시니어 여행 / 시니어 금융 / 시니어 헬스케어 / 시니어 일자리 / 시니어 리테일.
:::

**보내시면 화면 위쪽에 이런 줄이 먼저 뜹니다.**

```
skill(/senior-compare-kr-global)
```

나리님은 커맨드를 치신 적이 없는데도요. **클로드 코드가 부탁 내용을 읽고, 여기에 맞는 커맨드를 스스로 찾아 켠 겁니다.** `.claude/commands/` 안에 커맨드마다 *"이건 이럴 때 쓴다"* 가 적혀 있어서, 그걸 보고 고르거든요.

::: tip 맨 위 ①에 적힌 이름과 조금 다르죠
같은 일을 하는 커맨드가 **두 벌** 들어 있어요. 앞에 챕터 번호가 붙은 `/1-4-senior-...` 는 **오늘 진행용**(안내 문구가 조금 더 들어 있음), 방금 켜진 `/senior-...` 는 나리님이 **오늘 이후로도 계속 쓰실 쪽**입니다. **하는 일은 같아요.**
:::

그래서 **평소 말하듯 부탁해도 정해진 틀이 나옵니다.** 커맨드는 외워야 하는 게 아니라, **외우면 빨라지는** 것뿐이에요.

**이어서 이런 게 뜹니다.**

```
Running 2 agents…

  senior-research-kr (국내 시니어 주거 조사) · 16 tool uses · 30.8k tokens
  ⎿  Fetch: https://naidum.org/?kboard_content_redirect=491

  senior-research-global (일본·미국 시니어 주거 조사) · 14 tool uses · 24.0k tokens
  ⎿  Web Search: 介護予防・日常生活支援総合事業 2015年 施行 2017年…

     (ctrl+b to run in background)
```

맨 윗줄 **`Running 2 agents…`** 를 봐주세요. 클로드 코드가 혼자 일하는 게 아니라, **조사원 둘을 동시에 붙여둔** 겁니다.

| 보이는 것 | 무슨 뜻인가 |
|---|---|
| `senior-research-kr` | **국내만** 맡은 조사원. `Fetch:` 줄이 지금 열고 있는 국내 페이지예요 |
| `senior-research-global` | **일본·미국**을 맡은 조사원. 검색어가 **일본어로** 나가고 있죠 |
| `16 tool uses · 30.8k tokens` | 각자 웹을 몇 번 뒤졌고 얼마나 읽었는지 |

둘을 **나란히** 돌리는 데는 이유가 둘 있어요.

- **시간이 절반**입니다. 국내 다 하고 나서 해외를 하면 두 배 걸려요.
- **수치가 안 섞입니다.** 한 조사원에게 두 나라를 다 시키면 어느 숫자가 어느 나라 건지 엉키거든요.

이렇게 **일을 쪼개 나눠 맡기는 구조**를 [2-1](/part2/2-1-agents)에서 본격적으로 뜯어봅니다. 지금은 *"안에서 여럿이 돌고 있구나"* 만 보시면 돼요.

조사에 **3~5분** 걸립니다. 웹을 실제로 뒤지고 있는 거예요.

기다리는 동안 **에이전트가 단계마다 말을 겁니다** — *"조사원 둘을 띄웠어요"*, *"양쪽 조사 끝났습니다"*, *"검수자에게 넘겼어요"*. 이 줄들이 보이면 잘 돌아가는 중이니 안심하세요.

다 돌면 `output/` 폴더에 **`<오늘 날짜>-<주제>.md`** 파일 하나가 생겨 있습니다.

::: details 중간에 "수정 필요"가 떠도 정상이에요
이런 게 지나갈 수 있습니다.

```
[검수 결과] 수정 필요
  ■ 지적 1. 시장 규모 수치에 발행일이 없습니다
```

**실패가 아니라 검수자가 일한 겁니다.** 에이전트 안에 만드는 쪽과 검사하는 쪽이 나뉘어 있어서, 지적이 나오면 고쳐서 다시 내요. 자세한 건 [2-4](/part2/2-4-harness)에서 다룹니다.
:::

### Step 2 — 결과 확인하기

화면에 대략 이런 게 흐릅니다.

```
국내 자료부터 찾아볼게요.

  ● 통계청 KOSIS — 고령자 가구 추계 조회
  ● 보건복지부 노인복지시설 현황 확인
  ● 일본 내각부 고령사회백서 확인

정리했습니다.

━━ 국내 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 고령자 가구 수 …  📎 국가데이터처 (2025-09-29)
...
```

**여기서 확인하실 건 모양이 아니라 두 가지예요.**

| # | 확인할 것 | 어디를 보나 |
|---|---|---|
| **1** | 국내와 해외를 **둘 다** 봤는가 | 국내 / 일본 두 덩어리가 있는지 |
| **2** | 숫자에 **📎 출처**가 붙었는가 | 매체명 + 발행일이 함께 있는지 |

**이 둘이 있으면 성공입니다.** 방금 그 브리프가 나리님 손에서 나왔어요 🎉

`⚠️ 미확인`은 **있어도 되고 없어도 됩니다.** 자료가 충분한 주제면 안 붙어요. 다만 **하나도 없는데 내용이 유난히 매끈하다면** 한 번 의심해보실 만합니다 — 에이전트가 모르는 걸 넘어갔을 수 있거든요.

::: details 안 되면 — 출처가 안 붙거나 한쪽 나라만 조사했을 때
그냥 이어서 말씀하시면 됩니다.

```
일본 쪽도 같이 조사해서 비교해줘. 숫자마다 출처랑 발행일도 붙여줘.
```

클로드 코드는 **대화를 이어서 고칠 수 있어요.** 처음부터 다시 할 필요 없습니다.
:::

## [실습 2] 기회 카드

**커맨드**: `/1-4-senior-biz-idea`

실습 1에서는 **주제 하나를 조사**했어요. 브리프는 "지금 상황이 이렇다"까지죠. 이번엔 **그 자료를 바탕으로 신규 기회 BM을 찾아봅니다.**

### Step 1 — 어떤 브리프를 쓸지 확인

커맨드를 치면 에이전트가 곧바로 만들지 않습니다.

```
/1-4-senior-biz-idea
```

`output/`에서 **방금 만든 브리프**를 찾아 이렇게 되물어요.

```
output/2026-08-08-시니어주거.md 를 찾았습니다.
이 브리프를 기반으로 기회 카드를 만들까요?
```

**답을 하셔야 다음으로 넘어갑니다.** 화면이 멈춘 게 아니라 나리님을 기다리는 중이에요. 맞으면 그대로 진행해 달라고 하시고, 다른 걸 쓰고 싶으시면 그 파일을 말씀하시면 됩니다.

::: tip 왜 굳이 물어보게 해뒀을까요
`output/`에 파일이 쌓이기 시작하면 **어느 브리프를 기반으로 삼았는지**가 결과의 성격을 통째로 바꿉니다. 엉뚱한 걸로 카드를 만들어놓고 나중에 알아채면 되돌리기 번거롭거든요.
:::

### Step 2 — 기회 카드 생성

확인이 끝나면 에이전트가 그 브리프를 다시 읽어 카드를 만듭니다. [위에서 보신 ②번](#오늘-손에-넣을-결과물-3종) 형태로 나와요. **성공 기준은 장수가 아니에요.**

| 확인할 것 | |
|---|---|
| 각 카드에 **`걸림돌`이 채워져 있는가** | 이게 이 실습의 핵심입니다 |
| 각 카드에 **📎 근거**가 붙어 있는가 | 매체명 + 발행일 |

::: tip 2장만 나와도 정상입니다
워크숍에선 보통 **3장** 나와요 (평소 `/senior-biz-idea`로 부르시면 3~5장). 그런데 **근거가 얕으면 에이전트가 일부러 장수를 줄입니다.** 명세에 이렇게 적어뒀거든요 — *"3장짜리 진짜가 5장짜리 가짜보다 낫다."*

숫자가 적다고 실패가 아니에요. **`걸림돌`과 `📎 근거`가 비어 있으면** 그때 다시 돌려보세요.
:::

**`걸림돌` 칸을 꼭 보세요.** 좋은 얘기만 늘어놓지 않고 **안 될 이유까지 적게** 해뒀거든요. 조사에서 **의사결정 재료**로 넘어가는 지점이 여기예요.

다 되면 `output/`에 **`<오늘 날짜>-<주제>-기회카드.md`** 가 하나 더 생깁니다.

## [실습 3] 주간 리포트

**커맨드**: `/1-4-senior-weekly-news`

앞의 둘은 **주제를 정해 깊게** 팠어요. 마지막 하나는 반대로, 주제 없이 **지난 한 주를 넓게** 훑습니다. 되묻는 것도 없으니 커맨드만 치시면 돼요.

```
/1-4-senior-weekly-news
```

국내외 뉴스·사례를 모아 [③번 형태](#오늘-손에-넣을-결과물-3종)의 리포트 한 장으로 정리해줘요. 끝나면 `output/`에 **`<오늘 날짜>-주간리포트.md`** 가 생깁니다.

::: tip 짧게 나와도 정상이에요 — 오히려 좋은 신호입니다
시니어 시장에 **매주 대단한 일이 일어나지는 않아요.** 조용한 주엔 핵심이 1~2개만 나오고, 정말 아무것도 없으면 *"이번 주는 특기할 만한 움직임이 없었습니다"*라고 씁니다.

에이전트에 **일부러 그렇게 지시해뒀어요.** 분량을 채우려고 약한 소식을 끼워 넣으면, 정작 중요한 주에 그게 안 보이거든요. 짧은 리포트는 실패가 아니라 **정직한 리포트**입니다.
:::

::: warning 다만 이건 구분하셔야 해요 — 조용한 주 vs 조사가 안 된 것
둘 다 짧게 나오지만 **📎 출처의 유무**로 갈립니다.

| | 어떻게 보이나 | 어떻게 하나 |
|---|---|---|
| **조용한 주** | 항목은 적어도 **📎 출처가 붙어 있음** | 정상. 그대로 두세요 |
| **조사가 안 됨** | **📎 출처가 하나도 없음** | 다시 돌려보세요. 그래도 같으면 *"지난 2주로 넓혀서 다시 훑어줘"* |
:::

## [정리] 만든 것들을 열어보는 법

방금 만드신 **세 파일이 다 `output/` 폴더**에 있어요. 파일명 앞의 날짜는 **실행한 날**이 자동으로 붙고, 주제 자리엔 나리님이 고르신 게 들어갑니다.

(실습 1은 커맨드를 직접 치지 않으셨지만, **켜진 건 결국 같은 커맨드**라 파일도 똑같이 남습니다.)

열어보는 방법은 두 가지예요.

| 방법 | 어떻게 |
|---|---|
| **파일 탐색기로** | 폴더의 `output/` 을 열면 됩니다. `.md` 파일은 메모장으로도 열려요 |
| **클로드 코드에게** | *"output 폴더에 뭐가 있는지 보여줘"* 라고 말하면 목록을 읽어줍니다 |

::: tip 이게 쌓이면 나리님만의 아카이브가 돼요
오늘은 세 개지만, 주제를 볼 때마다 하나씩 쌓입니다. 반년 뒤엔 **시니어 시장을 나리님 관점으로 정리한 자료 뭉치**가 돼 있을 거예요.
:::

## [체크포인트] 오늘의 하이라이트를 확인해요

- **국내·해외 비교 브리프를 받으셨나요?** (📎 출처가 붙어 있는지 확인해보세요)
- **커맨드를 치지 않으셨는데 `skill(/senior-compare-kr-global)` 이 떴나요?** 클로드 코드가 부탁을 읽고 스스로 고른 겁니다.
- **`Running 2 agents…` 를 보셨나요?** 안에서 조사원 둘이 동시에 돌고 있었어요.
- **기회 카드까지 보셨나요?** 조사가 "그래서 뭘 하지"로 넘어가는 감이 오셨나요?
- **`output/` 폴더를 열어보세요.** 오늘 만든 파일들이 실제로 쌓여 있습니다.
- **⚠️ 미확인 항목이 있었나요?** 있었다면 에이전트가 **지어내지 않았다**는 뜻이에요. 없었다면 자료가 충분했던 거고요 — 둘 다 정상입니다.
