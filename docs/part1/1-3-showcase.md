# 1-3. 자동화, 어디까지?

::: tip Step 3 / 8 · Part 1
직접 만져보기 전에, 먼저 구경부터 하시죠. 강사가 실제로 운영 중인 **부동산 딜 에이전트**를 통째로 열어 보여드릴게요.

이 챕터는 손을 쓰지 않으셔도 돼요. 대신 다음 챕터에서 나리님이 직접 돌리실 봇이 어떤 모습일지, 여기서 먼저 그림을 잡으시면 됩니다.
:::

## [보기] 강사의 콘텐츠 에이전트 — 지시 한 줄로

강사는 **딜 아카이브**(상업용 부동산 거래를 카드뉴스로 정리하는 채널)를 클로드 코드 에이전트로 운영해요. 강사가 시키는 건 사실상 한 줄이에요.

> "이번 주 딜 찾아서, 사실 확인하고, 카드뉴스로 만들어줘."

그러면 에이전트가 **세 가지 기능**을 이어서 해냅니다. 실제로 돌아간 과정을 그대로 보여드릴게요.

### ① 기사 리서치 기능 — 딜을 찾아온다

강사가 한 건 `run_crawl.sh` 한 줄 실행뿐이에요. 그러면 에이전트가 뉴스를 크롤해 상업용 부동산 거래 후보를 모으고, 자동으로 걸러 **후보 풀**을 갱신합니다.

```
크롤 정상 완료 (2026-07-17 13:02)
- gnews 리드 85건 수집 → 신규 후보 4건 추가 · 탈락 26건
- 후보 풀 총 23건 유지 (news_candidates.json)
```

새로 찾아온 딜은 위치·보도가와 함께 정리돼 나와요.

| 딜 | 보도가 | 위치 |
|---|---|---|
| 그랜드 성수 (준공 전 매각) | 미정 | 성동구 성수동 |
| JB금융 여의도 사옥 (매각 검토) | 1,000억 | 중구 서소문동 |
| 오렌지센터 (5월 오피스 거래) | 6,466억 | 중구 순화동 |

단순 수집이 아니에요. **중복·무관한 건 제외키워드(분양·재개발·아파트)로 걸러내고**, 쓸 만한 후보만 남깁니다. 심지어 *"이건 '분양' 키워드에 걸려 탈락했지만, 실제론 유효한 딜일 수 있어요"*처럼 **걸러낸 것까지 되짚어** 알려줘요.

### ② 제안 기능 — 뭘 만들지 골라준다

모은 후보 23건을 훑어 **카드화 가치**로 평가하고, 등급을 매겨 추천해요. 이미 만든 6건은 빼고요.

```
A급 (단일딜·한국·최신·확정 가능)
- 넷마블 구로 지타워 6,976억 (넷마블 → 지베스코자산운용 리츠) — 최대 규모·화제성
- JB금융 여의도 사옥 1,000억 (서소문 신사옥 이전) — 깔끔한 단일딜
- 태영건설 독산동 노보텔 부지 (부채감축 매각)

B급 (딜은 유효하나 확인 필요)
- ABL생명 여의도 사옥 4,000억 → 우리금융
- 두산타워 매입 추진 (이지스-NH)

제외 권장
- 시장통계 기사(단일 딜 아님) · 해외 건(오스틴 오피스)
```

단순히 목록만 주는 게 아니라 "**이건 최대 규모라 화제성이 커요", "이건 아직 확인이 필요해요**"처럼 이유를 달아 골라줘요. 그리고 여기서 놀라운 지점 — 추천하기 전에 **사실을 스스로 교차검증**합니다. (정규식으로 뽑은 매도·매수 주체엔 파싱 오류가 섞일 수 있어, 선정 전 기사 원문으로 확정해요.)

::: tip 에이전트가 잡아낸 오류 (팩트체크)
- **"보도가 6,862억? 원문 확인하니 875억이네요."** — 크롤 단계 파싱 오류를 기사 원문으로 잡아냄
- **"JB금융은 아직 매각 '검토' 단계 — 확정가·매수자 없음."** — 확정 딜이 아닌 걸 구분해 "매각 추진 중"으로만 표기 제안
- 출처가 다르면 **어느 매체가 어느 수치의 근거인지** 나눠서 표기 (땅집고=875억 / 서울경제=매입가)
:::

### ③ 콘텐츠 제작 기능 — 카드뉴스 제작 자동화

맨 앞의 지시 한 줄이 여기까지 이어져요. 에이전트가 실제로 하는 일은 이렇습니다.

```
① 조회   fetch_property.py --address "금천구 독산동 1030-1"
         건축물대장 표제부 + 매칭 실거래 → 카드 초안(config) 자동 생성

② 확정   초안의 빈칸을 기사 확정값으로 채움 — 추정 금지

③ 렌더   build_cards.py --config <초안> --ratio 4x5
         1080×1350 PNG 4장 — 커버 / 실거래가 / 인사이트 / CTA
```

배경의 위성사진은 에이전트가 **카카오맵을 열어 직접 캡처해 가공한** 것이에요. 사람이 이미지를 찾아 넣지 않았습니다.

아래가 실제 산출물이에요.

| | |
|:---:|:---:|
| ![커버](/showcase/01_cover.png) | ![실거래가](/showcase/02_data.png) |
| ![인사이트](/showcase/03_insight.png) | ![CTA](/showcase/04_cta.png) |

**만들고 끝이 아니에요.** 에이전트는 자기가 만든 PNG를 **다시 열어봅니다.** 형태·색·실데이터·지도·한글 깨짐을 눈으로 확인하고, 이상하면 고쳐서 재렌더해요. 건물 사진이 들어간 카드라면 *"이 건물을 처음 보는 사람이 간판을 알아볼 수 있나"*까지 봅니다 — 가려졌으면 프레이밍을 바꿔 다시. 최대 두세 번, 스스로요.

카드에는 **출처가 명기**돼 있어요("출처: 땅집고·서울경제 / 국토부 실거래 아님"). 그리고 공개된 개발 이미지가 없자 에이전트는 "**없는 걸 지어내지 않겠다**"며 부지 위성뷰로 대체했어요 — 일반 안심주택 사진을 갖다 쓰면 이 딜과 무관한 조작 이미지가 되니까요.

::: tip 다음은 직접 돌려볼 차례
"나도 이 정도 수준으로 자동화가 가능하겠구나."

지금까지 '클로드 코드로 자동화'가 막연하셨다면, 이제는 **에이전트를 정의하고, 에이전트들의 협업 구조를 설계해서** 자동화를 해봅니다. 재능이 아니라 **배울 수 있는 구조**예요.

| 방금 본 장면 | 이걸 만든 것 | 배울 곳 |
|---|---|---|
| 리서치 → 제안 → 제작이 이어짐 | 에이전트를 나누고 붙이는 법 | [2-1](/part2/2-1-agents) |
| 출처를 대고, 추정을 안 함 | 에이전트에게 **규칙을 적어주는** 법 | [2-2](/part2/2-2-prd) |
| 만든 걸 스스로 다시 검수 | **만드는 쪽과 보는 쪽**을 나누는 법 | [2-3](/part2/2-3-harness) |

Part 2를 마치실 때쯤이면, 이 표의 **가운데 칸이 전부 나리님 손에** 있습니다.

그리고 그 전에 — 이제 나리님의 **시니어 리서치 봇**을 직접 돌려봅니다. 강사는 **부동산 딜**을 찾아왔죠. 나리님은 **시니어 시장**을 찾아올 겁니다. 같은 원리, 다른 도메인이에요.

봇은 **이미 폴더에 들어 있습니다.** 오늘 하실 일은 만드는 게 아니라 **부리는 것**이라, 뭘 조립하실 필요 없어요.
:::
