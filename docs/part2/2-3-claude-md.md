# 2-3. `CLAUDE.md` 활용법

::: tip Step 7 / 8
2-2에서 **무엇을 만들지**(PRD)를 잡았어요. 이번엔 그게 **실제로 사는 파일**을 엽니다.

오늘 배우는 것 중 **가장 오래 쓰실 것**이기도 해요 — 시니어 리서치를 그만두셔도 남는 습관이거든요.
:::

## [개념] 매 세션 자동으로 읽히는 파일

> `CLAUDE.md`는 클로드 코드가 **매 세션마다 자동으로 읽는** 프로젝트 설정 파일입니다.

나리님이 따로 말하지 않아도 **항상 배경에 깔립니다.** 1-4에서 브리프가 **매번 같은 형태로** 나온 이유가 이거예요.

**CLAUDE.md 없이:**

> "나는 시니어 시장을 보는 기획자야. 국내랑 일본을 비교해서 조사하되, 시차는 같은 지표에 도달한 연도로 계산해서 몇 년인지 밝혀줘. 수치엔 출처랑 발행일을 붙이고, 확인 안 된 건 미확인이라고 표시해줘. 그리고…"
>
> → **매번 새 대화마다 같은 설명을 반복**해야 합니다.

**CLAUDE.md 있으면:**

> "시니어 여행 시장 조사해줘"
>
> → 클로드가 이미 맥락을 알고 있어서 **바로 시작**합니다.

> `CLAUDE.md`는 프로젝트의 "**헌법**"과 같습니다. 개별 프롬프트보다 우선 적용되고, 명시적으로 고치지 않는 한 계속 유지돼요.

## [개념] 우리 `CLAUDE.md`엔 뭐가 적혀 있나

1-4에서 나리님이 돌린 파이프라인이 지킨 규칙들이에요. **다섯 줄이 전부**입니다.

> 1. 모든 수치·주장에 **📎 출처(매체명 + 발행일)** 를 붙인다.
> 2. 확인하지 못한 항목은 **⚠️ 미확인**으로 분리해 표시한다.
> 3. 근거가 없으면 **지어내지 않는다.** 추정이면 "추정"이라고 쓴다.
> 4. **국내 수치와 해외 수치를 절대 섞지 않는다.**
> 5. 투자·의료 판단은 **단정하지 않는다.**

::: tip 이 다섯 줄이 신뢰도의 전부예요
리서치는 틀리면 **사업 판단이 틀어집니다.** 시장 규모를 한 자릿수 잘못 읽으면 사업 계획 전체가 흔들려요. 그래서 원칙은 하나 — **근거 없는 단정보다 "모른다"가 낫다.**
:::

여기에 **비교 축**(일본 고정 + 미국 보조)과 **시차 계산 규칙**([1-4](/part1/1-4-agent)에서 보신 그것), **리서치 소스 우선순위**([부록 A](/appendix#a-리서치-소스-지도))가 함께 들어 있습니다.

## [개념] 담으면 좋은 것

나리님이 나중에 **다른 프로젝트**에서 쓰실 때의 목록이에요.

| 항목 | 예시 |
|---|---|
| 프로젝트 개요와 목적 | *"시니어 시장을 국내·해외 교차로 조사한다"* |
| **PRD** | [2-2](/part2/2-2-prd)에서 본 그 명세 (조사 소스 · 비교 축 · 출력 형식) |
| 용어 규칙 | `ALWAYS '시니어'가 아니라 나이대·거주형태까지 좁힐 것` |
| 톤앤매너 | *"단정보다 근거. 길게 쓰지 않는다"* |
| **금지 사항** | `NEVER 출처 없는 수치를 쓰지 말 것` |

::: tip 금지 사항을 꼭 넣으세요
*"~해줘"* 보다 ***"~하지 마"*** 가 더 잘 지켜집니다. 우리 `CLAUDE.md`도 **지어내기 금지 · 수치 혼동 금지**가 가장 강한 문장이에요.
:::

## [실습] 직접 쓰지 않아도 돼요

파일을 열어 편집하실 필요 없어요. 클로드 코드와 대화하다가 **이 한 줄**이면 됩니다.

```
지금까지의 내용을 CLAUDE.md에 저장해줘
```

새 프로젝트를 시작하실 땐 이것도 있어요.

```
/init
```

클로드가 폴더를 훑어보고 **`CLAUDE.md` 초안을 자동으로 만들어줍니다.**

::: tip 이게 오늘 배우는 것 중 가장 오래 쓰실 겁니다
시니어 리서치 에이전트를 쓰지 않게 되더라도, **"반복 설명을 `CLAUDE.md`에 넣어둔다"** 는 습관은 클로드 코드를 쓰는 내내 유효해요. 새 프로젝트를 시작할 때마다 제일 먼저 하시면 됩니다.

*"어? 이 설명 지난번에도 했는데"* 싶은 순간이 오면, 그때가 바로 넣을 때입니다.
:::

::: tip [체크포인트] 여기까지 잡으셨다면
- `CLAUDE.md` = **매 세션 자동으로 읽히는** 프로젝트 "헌법"
- 우리 것엔 **다섯 줄의 절대 규칙** + 비교 축 + 시차 계산 규칙 + 소스 우선순위가 들어 있다
- 담으면 좋은 것 = 개요 · **PRD** · 용어 규칙 · 톤앤매너 · **금지 사항**
- 직접 쓰지 않아도 됨 → **`"지금까지의 내용을 CLAUDE.md에 저장해줘"`** 한 줄
- 새 프로젝트엔 **`/init`**
:::
